# ChatS IM

ChatS IM 是一个开源的 Android 短信与拨号应用，在 [Simple-Dialer](https://github.com/SimpleMobileTools/Simple-Dialer) 与 [Simple-SMS-Messenger](https://github.com/SimpleMobileTools/Simple-SMS-Messenger) 的基础上合并改造，并围绕运营商「一卡多号」业务重新设计了消息与通话的归属模型。

## 开发初衷

国内运营商（如中国移动「和多号」、中国联通「沃小号」、中国电信「天翼小号」）提供基于主号的虚拟号码（小号）服务：拨打小号通常要在号码前加拨号前缀，收到的短信与来电则会带上信息前缀。但国内 ROM 自带的短信与拨号应用普遍不识别这些前缀——所有小号的短信混在同一会话里，回复时也不会自动加前缀，小号几乎无法正常使用。

ChatS IM 的目标就是补上这一块：

- 把「角色（小号）」作为一等公民：短信/来电按前缀自动归属到对应角色，回复/拨号自动添加对应前缀；
- 短信与通话记录按角色隔离成独立会话，不再混淆；
- 在此之上提供规则、回收站、定时消息等现代短信应用能力；
- 全部功能在本地完成，不联网、不收集数据。

## 核心概念

- **角色（小号）**：一条通信身份，分为两种：
  - **SIM 角色**：每张活动 SIM 卡一个，无前缀，绑定订阅；
  - **虚拟角色（小号）**：运营商小号，持有**信息前缀**与**拨号前缀**两个前缀。
- **通道前缀**：信息前缀用于短信/彩信，拨号前缀用于来电与拨出电话；两个前缀相互独立、不回退，某通道留空即表示该通道不使用小号。
- **会话**：以 `(角色, 对端号码)` 为唯一键；号码入库前会剥离前缀，因此同一个小号与同一对端的短信/通话会聚合成独立于其他角色的时间线。
- **规则引擎**：统一处理角色解析与消息筛选。内置规则负责小号前缀识别与黑名单；用户规则可按号码、角色、内容、短信/通话记录等条件执行「打标签 / 拦截 / 移入垃圾箱」。

## 功能

### 支持

- **短信 / 彩信**：短信收发、彩信接收、系统短信库同步、通知直接回复、送达报告、定时消息（短信）
- **通话**：默认拨号应用、来电界面（支持滑动接听）、拨号盘、通话记录、后台通话悬浮窗
- **角色（小号）**：SIM 角色 + 虚拟角色、信息/拨号双前缀、出入站自动识别与加前缀、会话与通话记录按角色隔离、按订阅选择发送/拨打
- **联系人**：系统联系人账号/分组筛选、置顶、拼音首字母索引、拨号盘首位前缀搜索、从 SIM 卡导入
- **规则**：添加标签 / 拦截 / 移入垃圾箱，手动运行、命中记录管理、内置「验证码」标签
- **回收站**：删除的短信与通话记录可恢复，支持按基准时间 + 周期自动清空
- **数据**：短信/彩信与通话记录的导入导出，本地文件备份与恢复
- **界面**：手机底部 TAB、大屏（≥600dp）左侧导航栏、Material 3 动态取色、深色主题
- **语言**：English / 简体中文

### 不支持

- **不联网**：未申请网络权限，无账号、无云同步、无在线备份，数据无法跨设备迁移；换机请使用导入导出
- **非 RCS / 5G 消息**：仅使用运营商传统短信与彩信通道
- **不支持发送彩信**：彩信仅支持接收与在时间线中提示附件
- **不支持应用私有联系人**：仅使用系统联系人
- **不支持通话录音**: 受系统约束
- **规则标签暂未在会话/聊天界面展示**：标签仅用于规则管理与后续扩展
- **仅 Android**：无 iOS / 桌面 / Web 版本
- **无号码归属地显示** 没有提供第三方的号码归属地查询服务
- **没有智能内容提取** 该功能还在开发中

## 用户政策

- **本地优先与隐私**：应用没有 `INTERNET` 权限，不联网、无广告、无统计；短信、通话、联系人与规则数据全部在设备本地处理，不会上传到任何服务器。
- **数据来源与保存**：作为默认短信与默认拨号应用，短信与通话记录以系统 telephony 数据库为准；本地数据库保存按角色聚合的会话、草稿、定时消息、回收站与规则数据。卸载应用会一并删除本地数据，重要数据请先导出备份。
- **权限用途**：短信、电话、联系人、通话记录、通知等权限仅用于实现对应功能；「显示在其他应用上方」仅用于后台通话悬浮窗，可拒绝或随时在系统中关闭。
- **拦截的局限**：黑名单与用户规则是尽力而为的本地过滤，可能存在误判或漏判；请勿把拦截当作唯一的安全措施。受系统省电策略影响，定时消息或通知可能延迟。
- **合规使用**：请遵守当地法律法规与运营商服务条款，不得将本应用用于发送垃圾信息、骚扰或欺诈。
- **无担保**：本项目按「现状」提供，不附带任何明示或默示担保。

## 发行版与验证

- 正式发行版在 [GitHub Releases](https://github.com/KylinLee/chatsim/releases) 发布，由 [`.github/workflows/release.yml`](.github/workflows/release.yml) 在推送 `v*` 标签时自动构建并签名；版本号以分支上的 `release(<major.minor.patch>): <description>` 提交为准。
- 每个 APK 均附带 `.sha256` 校验文件；签名证书的 SHA-256 / SHA-1 指纹与校验方法见 [SIGNING.md](SIGNING.md)。

## 贡献

- **只接受两类 PR**：bug 修复与安全漏洞修复。提交时请说明问题、复现步骤与验证结果。
- **新功能请先提 Issue**：说明使用场景与设计思路，便于讨论；不接受未经讨论的新功能 PR。
- **欢迎 Fork**：想要自己的功能？直接 fork 一份自行定制即可（需遵守 GPL-3.0，见下）。
- 参与前请阅读 [AGENTS.md](AGENTS.md)，并确保 `.\gradlew.bat testCoreDebugUnitTest` 与 `.\gradlew.bat assembleCoreDebug` 通过。
